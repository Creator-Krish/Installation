# BuildForge User Guide

## Quick start

1. Open the landing page.
2. Describe the website or mobile app in one sentence.
3. Review the three AI-generated design variations.
4. Open the studio workspace.
5. Edit components visually or ask the AI assistant to make changes.
6. Review the generated data model and deployment path.

## Editor layout

- Left sidebar: Component library and page tree
- Center canvas: Live preview area with breakpoint switching
- Right sidebar: Contextual properties and backend bindings
- Bottom dock: AI chat, logs, and future collaboration tools

## Best practices

- Start with outcome-focused prompts
- Specify audience, business goal, and must-have features
- Pick one variation before deep customization
- Use the AI assistant for content and structural changes before manual polish
